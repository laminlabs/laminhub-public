# `laminhub-public`

Version: `1.58.1`

This public repository allows you to make issues and follow new releases. It
does not contain the private `laminhub` application source code.

## Status page

The [`status`](status) directory contains the public status-page components.
The first component exports Sentry uptime measurements into `lamin-qms` for
long-term storage. The independently hosted status UI will be added later.
